# Rave Games

A fork of the Dot Opera project for *Gaz '89*: twelve very small LittleJS games about trying to get to your first M25 rave in Essex, 1989. One mechanic per level, one sprite for Gaz, under 128 KB each, the story told by the order they come in.

- `docs/GAZ-89.md` is Iain's brief, verbatim.
- `docs/PLAN.html` is the build plan for approval: the shared shell, the level specs, the test loop, who builds what, and the questions still open.

Nothing is built yet. The arcade (`../arcade`) is the sibling fork this one borrows its build script, synth and test harness from.
