# The dot opera prompt

Replace `OPERA` and run. One agent, one file.

---

Please take the opera **OPERA** and convert its story into a dot opera, retaining the key plot points for a super-condensed retelling.

You must also take the most recognisable part of the opera's music and use it to soundtrack the dot opera.

A full set of rules for designing dot operas is in `docs/DOT-OPERA-RULES.md` in `/Users/iaintait/Code/12kb-techno-opera`. Read it first. The engine's vocabulary is in `docs/engine-api.md`, and `operas/carmen.js` is a finished example.

Feel free to suggest new ways to tell the story, but you must stick to the core principles of dot opera. Max opera, minimum filesize.

Write `operas/<id>.js`, build it with `npm run build`, check it with `?gate=` as the rules describe, and report back with its size, the plot points you kept, the tune you used, and any new way of telling you tried.
